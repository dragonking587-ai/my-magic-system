Tip: This editor commits directly to your repo using GitHub OAuth (PKCE). No Netlify, no servers.

Setup

  1. Set owner, repo, and branch (usually main).
  2. Click Set GitHub Token.
  3. Click Load book files, then pick a chapter/part file.
  4. Edit → Save to commit.

Open GITHUB_ONLY_TOKEN_SETUP.md in the repo for exact steps on creating a fine‑grained token.
